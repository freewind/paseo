# 上游 React 组件复用索引

> 列出上游 `main` 中**导出的 React 组件**，按功能域分组，供开发新功能时复用。只统计项目自定义组件，不含 Hook、工具函数、类型、第三方组件与测试/示例代码。

## 基准与口径

- 分析基准：本地 `upstream/main` 提交 `1aef1ec6625f2c32cbd62cfbeb02cffb43a275d2`，未联网更新。
- 只收录从模块导出的 React 组件，不论是否被使用；私有组件不列。
- `memo`/`forwardRef`/`withUnistyles` 包装计一次；重导出不重复计数。
- 同名组件的多平台实现合并为一行，限制列标注平台差异。
- “功能”为中文，综合组件名称、props 能力与实现要点；“分类”区分通用/业务。使用前请核对当前 fork 的源码与接口。

共 **725** 个导出组件，分组如下：通用基础 **105**，其余为各功能域业务组件、网站与插件组件。
